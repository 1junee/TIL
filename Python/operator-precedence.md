# 연산자 우선순위

작성일: 2026-10-26

| 순위 | 연산자 | 의미 |
| --- | --- | --- |
| 1 | `(식)` | 괄호 안의 식을 먼저 계산 |
| 2 | `**` | 거듭제곱 |
| 3 | `+x`, `-x` | 부호 |
| 4 | `*`, `/`, `//`, `%` | 곱셈, 나눗셈, 내림 나눗셈, 나머지 |
| 5 | `+`, `-` | 덧셈, 뺄셈 |
| 6 | `<`, `<=`, `>`, `>=`, `==`, `!=`, `in`, `not in`, `is`, `is not` | 비교, 포함 여부, 객체 동일성 |
| 7 | `not` | 논리 부정 |
| 8 | `and` | 논리 AND |
| 9 | `or` | 논리 OR |

```python
print(-2 ** 2)         # -4: -(2 ** 2)
print((-2) ** 2)       # 4
```

같은 우선순위의 산술 연산자는 보통 왼쪽부터 묶지만, `**`는 오른쪽부터 묶는다.
복잡한 식은 괄호로 의도를 드러내면 읽기 쉽다.

`//`는 결과를 아래쪽 정수로 내리므로, 음수에서는 소수 부분을 버리는 것과 다르다.
`-7 // 2`의 결과는 `-4`다.
