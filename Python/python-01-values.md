## 1. 연산자 우선순위


| 순위 | 연산자 | 의미 |
| --- | --- | --- |
| 1 | `(식)` | 괄호 안의 식을 먼저 계산 |
| 2 | `**` | 거듭제곱 |
| 3 | `+x`, `-x` | 부호 |
| 4 | `*`, `/`, `//`, `%` | 곱셈, 나눗셈, 내림 나눗셈, 나머지 |
| 5 | `+`, `-` | 덧셈, 뺄셈 |
| 6 | `<`, `<=`, `>`, `>=`, `==`, `!=`, `in`, `not in`, `is`, `is not` | 비교, 포함 여부, 객체 동일성 |
| 7 | `not` | 논리 부정 |
| 8 | `and` | 논리 AND |
| 9 | `or` | 논리 OR |

```python
print(-2 ** 2)         # -4: -(2 ** 2)
print((-2) ** 2)       # 4
```

같은 우선순위의 산술 연산자는 보통 왼쪽부터 묶지만, `**`는 오른쪽부터 묶는다.
복잡한 식은 괄호로 의도를 드러내면 읽기 쉽다.

`//`는 결과를 아래쪽 정수로 내리므로, 음수에서는 소수 부분을 버리는 것과 다르다.
`-7 // 2`의 결과는 `-4`다.

## 2. 문자열 포매팅

문자열에 변수나 계산 결과를 넣을 때는 주로 f-string을 사용한다.
문자열 앞에 `f`를 붙이고, `{}` 안에 변수나 식을 넣는다.

| 형식 지정자 | 의미 |
| --- | --- |
| `:.2f` | 소수점 아래 두 자리까지 표시 |
| `:,` | 천 단위 구분 기호 추가 |
| `:03d` | 정수를 최소 세 자리로 표시하고, 빈 앞자리를 `0`으로 채움 |

형식 지정자는 `{값:형식}`으로 사용하며, 원래 변수의 값은 바꾸지 않는다.

- **`str.format()`**: `{}`에 전달한 값을 넣는다. `{:.2f}`처럼 형식 지정자도 사용할 수 있다.
- **`%` 포매팅**: `%s`는 문자열, `%d`는 정수, `%f`는 실수다. 여러 값은 튜플로 묶어 전달한다.

```python
print("{}: {:.2f}".format("점수", 95.678))  # 점수: 95.68
print("%s: %.2f" % ("점수", 95.678))       # 점수: 95.68
```
