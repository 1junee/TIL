# Today I Learned

새롭게 배운 개념과 개발 과정에서 해결한 문제를 기록하는 공간입니다.
나중에 다시 읽고 활용할 수 있도록, 이해한 내용을 작은 단위로 정리합니다.

## 작성 규칙

- 문서는 주제별로 나누어 Markdown(`.md`)으로 작성합니다.
- 폴더와 파일명은 내용을 알 수 있는 영문으로 작성합니다.
- 이해한 내용을 자신의 말로 정리하고, 참고 자료의 출처를 남깁니다.
- 분량이나 매일 작성하는 것에 얽매이지 않고, 다시 읽었을 때 도움이 되는 기록을 남깁니다.

## 분류

날짜별 폴더 대신 기술과 주제별 폴더로 분류합니다.
현재는 `Python`부터 시작하며, 다른 분야의 기록이 생기면 필요한 폴더를 추가합니다.
각 폴더의 `README.md`에는 해당 분야의 학습 기록 링크를 모읍니다.

| 분류 | 내용 |
| --- | --- |
| [Python](./Python/README.md) | Python 문법, 자료형, 함수, 객체 지향, 라이브러리와 문제 해결 |

```text
TIL/
├── README.md
└── Python/
    ├── README.md
    ├── python-startkit.md
    ├── python-01-values.md
    ├── python-02-flow.md
    └── python-03-collections.md
```

## 문서 작성 예시

아래 틀을 기본으로 사용하되, 주제에 맞게 항목을 줄이거나 추가합니다.
새 문서를 작성하면 해당 분류의 `README.md`에 링크를 추가합니다.

```markdown
# 주제

작성일: YYYY-MM-DD

## 배운 내용

핵심 개념과 동작 원리를 자신의 말로 정리합니다.

## 예제

직접 확인한 코드와 실행 결과를 기록합니다.

## 정리

기억할 점, 주의할 점, 추가로 알아볼 내용을 적습니다.

## 참고 자료

- [자료 제목](URL)
```
