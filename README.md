# Today I Learned

새롭게 배운 개념과 개발 과정에서 해결한 문제를 기록한다.
나중에 다시 읽고 활용할 수 있도록, 이해한 내용을 작은 단위로 정리한다.

## 작성 규칙

- 문서는 주제별로 나누어 Markdown(`.md`)으로 작성한다.
- 문서 하나에는 주제 하나만 정리한다.
- 폴더와 파일명은 내용을 알 수 있는 영문으로 작성한다.
- 이해한 내용을 자신의 말로 정리하고, 참고 자료의 출처를 남긴다.
- 분량이나 매일 작성하는 것에 얽매이지 않고, 다시 읽었을 때 도움이 되는 기록을 남긴다.

## 문서 작성 예시

아래 틀을 기본으로 사용하되, 주제에 맞게 항목을 줄이거나 추가한다.
새 문서를 작성하면 해당 폴더의 `README.md`에서 알맞은 소주제 아래에 링크와 작성일을 추가한다.

```markdown
# 주제

작성일: YYYY-MM-DD

## 배운 내용

핵심 개념과 동작 원리를 자신의 말로 정리한다.

## 예제

직접 확인한 코드와 실행 결과를 기록한다.

## 정리

기억할 점, 주의할 점, 추가로 알아볼 내용을 적는다.

## 참고 자료

- [자료 제목](URL)
```
